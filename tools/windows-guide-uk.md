RL2 Co-op: як перевірити мод на Windows
=========================================

Потрібно: Windows 10/11, Rogue Legacy 2 у Steam, цей архів.
Займе 10 хвилин. Якщо щось пішло не так, надішли файл
BepInEx\LogOutput.log (пункт 4).

1. Знайди папку гри
   Steam → Бібліотека → Rogue Legacy 2 → правою кнопкою → Керування →
   Переглянути локальні файли. Відкриється папка, де лежить
   "Rogue Legacy 2.exe".

2. Розпакуй архів у цю папку
   Вміст архіву (winhttp.dll, doorstop_config.ini, папка BepInEx і цей
   файл) має лежати поруч з "Rogue Legacy 2.exe", а не в окремій підпапці.

3. Запусти гру зі Steam, як завжди
   На Windows нічого в параметрах запуску міняти не треба. Перший запуск
   триває на кілька секунд довше: BepInEx (завантажувач модів) готує свої
   файли.

4. Перевір, що мод завантажився
   Відкрий BepInEx\LogOutput.log у папці гри. Там має бути рядок
       RL2 Co-op ready. Press F8 in game to host or join.
   Якщо рядка немає або файлу немає, мод не запустився: надішли нам цей
   файл (або повідомлення, якщо файлу немає взагалі).

5. Гра вдвох
   Хто приймає гру (хост): у грі натисни F8 → Host.
     Windows спитає про брандмауер (захист мережі): натисни "Дозволити",
     постав обидві галочки (приватні й публічні мережі).
   Хто приєднується (гість): F8 → у полі Address впиши адресу хоста → Join.
     Адреса — IP хоста (наприклад 192.168.1.20) або ім'я комп'ютера.
   Далі хост заходить у замок, гість заходить у замок зі свого маєтку й
   опиняється в тій самій кімнаті.

6. Гра через інтернет
   Найпростіше: обидва ставлять Radmin VPN, ZeroTier або Tailscale
   (безкоштовні програми, що створюють спільну "домашню" мережу через
   інтернет), і гість вписує адресу хоста з цієї програми.
   Інакше: хост відкриває на роутері порт UDP 26950 (port forwarding),
   а гість вписує зовнішній IP хоста.

Що перевірити й написати нам
   [ ] рядок з пункту 4 є
   [ ] гість приєднався (у кутку екрана обидва гравці й пінг)
   [ ] кожен бачить іншого героя, як той ходить і б'є
   [ ] вороги, яких б'є гість, гинуть в обох
   [ ] коли один гине, він дивиться за іншим ([ і ] перемикають)

Налаштування: BepInEx\config\rl2coop.cfg (з'являється після першого
запуску). Ім'я гравця: PlayerName у розділі [Session].

Прибрати мод: видали winhttp.dll і doorstop_config.ini з папки гри.
Гра знову запускатиметься без модів.
